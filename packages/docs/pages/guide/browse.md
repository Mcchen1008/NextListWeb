文件页是 NextList 的日常主界面。本文按「列表 → 预览 → 下载」的使用链路介绍各能力。

## 文件列表

文件页以目录树 + 内容区的形式呈现：左侧目录树聚合所有已挂载的存储，右侧展示当前路径下的文件与文件夹。列表与网格两种视图可以随时切换，网格模式对图片类目录提供缩略图墙体验。支持按名称、大小、修改时间排序，排序方式由服务端统一处理（各网盘驱动的返回顺序会被归一化）。分页形式（全部加载 / 翻页 / 加载更多）由管理员在[站点设置](/config/site)中选择。

对文件与文件夹的常规操作在工具栏与右键菜单中：新建文件夹、重命名、批量重命名（支持模板规则）、移动、复制、删除、清理空目录。复制与移动可以跨越不同存储进行——例如把 115 网盘的文件复制到夸克，服务端会通过驱动抽象自动完成搬运。

## 文件预览

NextList 对常见格式提供开箱即用的在线预览，按扩展名自动匹配：

| 类型 | 覆盖格式 | 能力 |
| --- | --- | --- |
| 视频 | mp4、mkv、webm、avi、mov、flv、m3u8、ts | 播放器支持外挂字幕、弹幕、倍速；支持 HLS 直链 |
| 音频 | mp3、flac、wav、ogg、aac、m4a、opus | 歌词展示、默认封面设置 |
| 图片 | jpg、png、gif、webp、svg、avif 等 | 画廊模式连续浏览、缩放 |
| 文档 | pdf、docx、pptx、xlsx | Office 三件套在线渲染，PDF 内嵌阅读器，另支持 epub |
| 文本 / 代码 | txt、json、js、ts、py、go、yaml、css 等 50+ 扩展名 | Monaco 编辑器、多主题、只读查看 |
| Markdown | md | 自动渲染，支持文件夹内 README.md 自动展示 |
| 其他 | ipa / plist、asciinema 录制等 | 专用预览分支 |

预览行为可以在[预览设置](/config/preview)中深度定制：调整各类型的扩展名清单、开启代理下载（`proxy_types`）、配置外置预览（`external_previews` / `iframe_previews`）、设置音视频自动播放、指定某种扩展名强制走某个预览器等。

> [!NOTE]
> 部分网盘（如百度网盘）对直链下载有限速或不允许跨域引用，遇到预览卡顿时可让管理员把对应扩展名加入 `proxy_types`，由服务端代理转发。

## README 与目录说明

若当前目录内存在 `README.md`（或 `readme.md`），文件页底部会自动渲染其内容，适合做合集说明、使用须知。管理员还可以通过[元数据（Meta）](/config/global)为任意路径强制指定隐藏的 README 内容或页头文案，并给目录加密码。

## 下载与打包

单文件下载走直链（`/d/...`），支持 HTTP Range 断点续传与多线程加速；需要中转的文件由服务端流式代理转发，不会在边缘完整缓存大文件。整个文件夹（或多个选中项）可以一键**打包下载**：服务端以流式 ZIP 边读边发，无需等待压缩完成即可开始下载，也不会占用额外存储空间。若管理员在[高级设置](/config/advanced)中关闭了打包下载（`package_download_disabled`），该入口会被隐藏。
