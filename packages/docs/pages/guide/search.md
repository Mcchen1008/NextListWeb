---
title: 文件搜索
description: NextList 的递归文件搜索——关键词匹配、范围过滤与分页
---

当文件散落在多层目录中时，搜索是比逐级点开更快的方式。NextList 内置递归搜索，从任意起点向下遍历目录树并按关键词匹配。

## 使用方式

点击文件页工具栏的搜索图标（或使用搜索快捷入口），输入关键词即可开始。搜索范围默认从当前目录（`/` 表示全站）向下递归；搜索会跨越存储边界——如果挂载了多个网盘，一次搜索即可覆盖所有已启用的存储。

结果支持两个维度的过滤：

- **范围（scope）**：`全部`（文件 + 文件夹）、`仅文件夹`、`仅文件`；
- **分页**：结果较多时按页展示，每页数量默认 100，可通过参数调整（上限 200）。

## 行为与限制

递归搜索采用广度优先（BFS）实现，为保护边缘运行时与网盘 API 配额，服务端对单次搜索施加了以下上限：

| 上限 | 值 | 说明 |
| --- | --- | --- |
| 递归深度 | 10 层 | 超深层级的目录不再向下展开 |
| 遍历目录数 | 500 个 | 防止超大目录树拖垮请求 |
| 命中数量 | 5000 条 | 命中计数达到上限即停止 |

> [!TIP]
> 如果搜索结果不完整，多半是触达了上述上限。先用更精确的关键词缩小范围，或把搜索起点改到更深的子目录。

对设置了密码的目录，搜索请求与浏览一样需要携带正确的密码，否则该子树不可达。搜索能力同样通过 REST API 暴露（`POST /api/fs/search`），便于脚本化使用，参数说明见 [REST API](/advanced/api)。
