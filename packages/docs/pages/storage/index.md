NextList 自身不存储任何文件，所有内容来自「存储（Storage）」：每条存储 = 一个驱动 + 一份凭证 + 一个挂载路径。本文介绍与驱动无关的通用流程；每个驱动的凭证获取方式见[驱动一览](/storage/drivers)。

## 挂载流程

1. 使用管理员账号登录，进入**管理面板 → 存储管理**；
2. 点击「添加存储」，在驱动下拉框中选择目标驱动（全部 51 个可选值见[驱动一览](/storage/drivers)）；
3. 填写挂载信息（下表）与驱动专属凭证；
4. 保存。新存储默认启用，可随时在列表中停用 / 启用；「检查存储」按钮可立即验证凭证有效性。

| 通用字段 | 必填 | 说明 |
| --- | --- | --- |
| 挂载路径（mount_path） | ✓ | 存储在目录树中的位置，如 `/夸克`、`/NAS/备份`；必须全局唯一 |
| 驱动（driver） | ✓ | 决定后端用哪种协议访问远端 |
| 排序（order） | | 数字越小目录树中越靠前 |
| 备注（remark） | | 仅管理员可见的备注 |
| 缓存时间（cache_expiration） | | 目录列表缓存秒数，默认 30；流量紧张或文件频繁变动时调整 |
| 启用（enabled） | | 关闭后该存储从目录树消失但配置保留 |

## 凭证填写通用技巧

各网盘驱动主要靠三类凭证接入，获取方式高度相似。**Cookie 类**（夸克、UC、天翼、腾讯微云、WPS、超星、豆包等）：在浏览器登录网盘网页版 → F12 打开开发者工具 → Network 标签 → 任选一个 API 请求复制请求头中的 `Cookie` 值，粘贴进存储表单即可。**Token 类**（123 云盘、迅雷、分秒帧等）：同样从请求头复制 `Authorization: Bearer xxx` 中 Token 部分；带 refresh_token 的驱动填 refresh_token 可长期自动续期。**OAuth 类**（阿里云盘 Open、OneDrive、Google Drive、Dropbox、115 Open 等）：按表单内指引完成授权，得到 refresh_token 填入，驱动会自动刷新访问令牌。

> [!TIP]
> Cookie 与 Token 都有有效期。NextList 会持久化驱动刷新后的新凭证（写入 KV），大多数驱动可以长期免维护；一旦失效，重新获取并覆盖即可，无需删除存储。

## 缓存与刷新

目录列表默认缓存 30 秒（`cache_expiration`），上传或远端变动后前台短暂不刷新属正常现象。两种立即刷新方式：存储管理中对目标存储执行「刷新」，或等待缓存自然过期。把缓存调大可以显著减少对网盘 API 的请求频率（对有严格配额的驱动很有用），调小则实时性更好。

## 排序与跨存储操作

所有网盘驱动的目录条目都遵循统一的排序规则，管理面板可配置 `order_by` / `order_direction`（名称、大小、时间）。挂载多个存储后，文件页可以跨存储复制、移动文件——例如把 115 网盘的整季剧集复制到夸克网盘，服务端经驱动抽象逐个搬运；受限于上游驱动能力，个别网盘不支持跨盘移动，此时用「下载到本地再上传」兜底。

## Serverless 环境注意事项

本地存储（Local）驱动只在 Node 容器模式可用；Cloudflare Workers 等边缘环境没有持久文件系统，请选择网盘或对象存储驱动。123 云盘对数据中心 IP 登录存在限制（详见[部署须知](/deploy/workers#网盘驱动与数据中心-ip-登录限制)），推荐使用官方开放平台授权获取 access_token。
