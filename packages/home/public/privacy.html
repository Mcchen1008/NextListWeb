隐私政策

生效日期：2026 年 9 月 11 日

本隐私政策说明 NextList 官网（含文档站与插件市场，合称「本站」）如何处理访问者信息。使用本站即表示你已阅读并同意本政策；若不同意，请停止使用本站。

我们收集的信息

本站秉持最小化收集原则。你不需注册即可浏览本站全部内容，我们不会主动收集你的姓名、邮箱、电话等身份信息。在正常访问过程中，我们的服务托管商（Cloudflare）会自动记录标准请求日志（IP 地址、访问时间、User-Agent、请求的页面），用于安全防护与故障排查；这类日志由托管商按其自身政策保存与处理。

当你使用插件市场的 GitHub 登录功能时，我们会通过 GitHub OAuth 获取你的 GitHub 用户名、数字 ID 与头像地址，仅用于标识插件作者身份与展示头像。我们不会获取你的 GitHub 邮箱，不会读写你的私有仓库，也不会在你未主动触发「刷新我的插件」时访问 GitHub API。你可以随时在 GitHub 的「已授权 OAuth 应用」设置中撤销授权。

Cookie 与类似技术

本站使用少量浏览器本地存储（Cookie / localStorage）维持必要功能：登录态、界面主题偏好、文档阅读位置等。这些存储不用于跨站追踪。

广告 Cookie：本站接入 Google AdSense 展示广告。Google 及其合作方可能使用 Cookie（含第三方 Cookie）依据你对本站及其他网站的访问投放个性化广告。你可以访问 Google 广告设置 管理个性化广告偏好，或访问 www.aboutads.info 选择退出部分第三方 Cookie。

第三方服务

  • Cloudflare（托管、CDN 与安全）— 隐私政策
  • Google AdSense（广告）— 隐私政策
  • GitHub（代码托管、OAuth 登录与评论系统）— 隐私政策
  • giscus.app（基于 GitHub Discussions 的评论服务，仅在你主动使用评论功能时交互）

这些服务可能向你所在的地区传输数据，具体取决于其全球网络架构。

自建实例说明

本站文档中出现的任何 NextList 部署实例均由部署者自行运营。你的 NextList 实例（自建的文件站点）完全由你自己控制：站点数据（存储凭证、用户、配置）保存在你自己的 Cloudflare KV / 数据库中，NextList 项目本身不回传任何数据到开发者服务器。

数据安全与你的权利

我们采取合理的技术措施（HTTPS 全站加密、最小权限原则）保护处理的信息。基于 GDPR / CCPA 等法规赋予的权利，你可以要求查询、更正或删除与你相关的个人信息——由于本站几乎不持有身份信息，此类请求通常应向上述第三方服务提出。联系我们：GitHub Issues。

政策更新

本政策可能随功能调整而更新，重大变更会在本页公布并更新生效日期。继续使用本站视为接受更新后的政策。
